痛点

Code review 是研发流程里最大的时间黑洞之一

而在小团队里，这道关通常根本不存在。
慢
人工审查等不起
一个 PR 排队半天，上线节奏被打乱；忙起来 review 变成「点个 Approve 走个过场」。
漏
肉眼看不全规则性缺陷
未使用变量、裸 except、越界索引——这类问题不靠工具就会漏，漏一次就是一次线上事故。
无
小团队没有 review 文化
3-5 人的团队没有专职审阅人，问题全部堆到生产环境才暴露，修复成本翻十倍。
我们缺的不是更聪明的代码补全，而是提交之前那道关。

Git diff 输入模式
